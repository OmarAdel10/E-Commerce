# Storefront components

The developer reference for app storefront components (sections, components, skins, templates, slots, settings, islands, testing and the packer) ships with the SDK: [`packages/plugin-sdk/docs/storefront.md`](../packages/plugin-sdk/docs/storefront.md). Theme developers start with [`themes.md`](../packages/plugin-sdk/docs/themes.md) (the portability rules `pnpm plugin validate` checks, the `--theme` starter and the three-store preview); AI tools read [`llms.txt`](../packages/plugin-sdk/docs/llms.txt).

The platform and app lifecycle is in [`apps.md`](../packages/plugin-sdk/docs/apps.md), and checkout functions, ports and the stable app API in [`commerce-hooks.md`](../packages/plugin-sdk/docs/commerce-hooks.md).
